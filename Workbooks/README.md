# Workbooks

## Ready When It Matters

A practical personal-readiness workbook designed to help people identify priorities, organize essential information and prepare clear instructions for others during emergencies or unexpected changes.

This sample demonstrates my approach to:

- Long-document editing
- Workbook design and production
- Information organization
- Plain-language instructions
- Tables, checklists and fillable activities
- Microsoft Word and PDF publishing
