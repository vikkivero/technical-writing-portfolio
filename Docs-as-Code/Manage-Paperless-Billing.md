# Manage paperless billing

Use the paperless billing setting to record how a customer wants to receive future bills.

> **Portfolio sample:** This user guide demonstrates my approach to clear, task-based product documentation.

## Before you begin

- Confirm that you have permission to update customer preferences.
- Verify the correct account and service address.

## Turn on paperless billing

1. Open the customer's account.
2. Select **Billing preferences**.
3. Under **Bill delivery**, select **Paperless billing**.
4. Confirm the customer's email address.
5. Select **Save**.

The system displays a confirmation message and records the change in the account history.
